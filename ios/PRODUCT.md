# WebCrunch for iOS
<!-- impeccable:product-schema 1 -->
## Platform
ios
## Stack
SwiftUI with a local JavaScriptCore bridge to WebCrunch's existing calculator.
## Product Purpose
A native version of the existing WebCrunch website with an in-app custom math keyboard. The user wants to try it without writing code.
## Capabilities and Constraints
Offline from first launch. Expressions, live preview, history, variables, user functions, degree/radian modes. Persist the calculation session locally. iPhone first, with an adaptive iPad layout. Finnish, Swedish, and English.
## Brand Commitments
The user explicitly selected the current WebCrunch website as the visual and behavioral reference. The separate legacy desktop project is not an implementation source.
## Open Decisions
Public distribution, account identity, and final app name beyond the existing WebCrunch name are not decided.
